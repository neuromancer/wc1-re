Wing Commander (Kilrathi Saga) source reconstruction
====================================================

This archive contains WC1.EXE rebuilt from the recovered source with the
original Microsoft Visual C++ 4.20 toolchain. It is not a copy of the retail
executable.

No copyrighted game data is included. To use this executable, make a backup
of WC1.EXE in an installed Kilrathi Saga WC1 directory and replace it with the
file from this archive. The reconstructed Win32 build can run on a compatible
32-bit Windows environment or through DREAMM.

The corresponding source is available from the Git tag attached to the same
GitHub Release. See LICENSE.txt for the project license.
