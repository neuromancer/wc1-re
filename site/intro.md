# Wing Commander reconstructed source

This is the [reconstructed C and C++ source](https://github.com/neuromancer/wc1-re)
of **Wing Commander** as shipped in *Wing Commander: The Kilrathi Saga* (1996),
with the SDL2 port's code stripped out. Built with Microsoft Visual C++ 4.20, it reproduces the original Win32
`WC1.EXE` byte for byte.

## Source files
Each group lists its files in link order, the order of their code in
`WC1.EXE`.
